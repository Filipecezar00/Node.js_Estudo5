#  Projeto My Gastronomy

Uma aplicação e-commerce completa (Full Stack) voltada para o setor de gastronomia, permitindo a navegação por pratos, gerenciamento de carrinho e autenticação segura.

---

##  Links dos Deploys
* **Front-end:** [Acessar a aplicação na Vercel](https://node-js-estudo5.vercel.app/profile)
* **Back-end (API):** [Acessar o servidor no Render](https://backendecommerce-0tui.onrender.com)

---

## Tecnologias Utilizadas

* **Front-end:** React.js
* **Back-end:** Node.js & Express
* **Banco de Dados:** MongoDB Atlas
* **Hospedagem/Deploy:** Vercel (Front-end) & Render (Back-end)

---

##  Principais Funcionalidades

* [x] **Autenticação Segura:** Cadastro de novos usuários e login com geração de Token JWT.
* [x] **Catálogo:** Listagem completa de pratos disponíveis.
* [x] **Carrinho de Compras:** Organização dinâmica dos pedidos antes da finalização.
* [x] **Gerenciamento de Pedidos:** Fluxo completo para processar as requisições.
